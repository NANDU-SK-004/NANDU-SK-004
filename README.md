<br/>

An indoor navigation system designed to help patients and visitors find their way inside hospital premises without needing to ask staff for directions — functioning as an indoor equivalent of outdoor GPS navigation for complex, multi-floor, multi-department buildings.

| Aspect | Details |
|:--|:--|
| **Stack** | Python, HTML, CSS, JavaScript |
| **Scale** | Multi-floor, multi-department indoor wayfinding |
| **Performance** | Optimized for quick, intuitive route lookup with no external dependencies |
| **Security** | N/A — standalone navigation utility, no sensitive data handling |
| **Impact** | Removes the friction of asking around for directions in unfamiliar buildings, improving the visitor/patient experience |
| **Repository** | [github.com/NANDU-SK-004/hospital-navigator](https://github.com/NANDU-SK-004/hospital-navigator) |

The core challenge was designing an intuitive indoor pathfinding experience in the absence of GPS signal — solving for usability in a way that mirrors outdoor map navigation, but adapted to indoor floor plans and points of interest.
